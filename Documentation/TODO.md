- [ ] **延后：TCP 高级特性。** 时间戳、ECN 协商、紧急数据及 TCP Fast Open 数据型 SYN；原始 ICMP Echo 另待范围确认，不把有界实现称为完整 RFC 栈。
- [ ] **macOS Network Extension 与真实系统 VPN。** 实现必要 Apple 平台协调和 Rust 数据面，验证实际接管、TUN 收发、路由、防回环、DNS 与代理转发；回环夹具不代替系统验收。
- [ ] **VPN Preflight 必要链路及系统检查。** 实际代理协议/数据路径、DNS 上游、资源、权限、环境与防回环，失败保留原方案。
- [ ] **无节点可信二次确认。** 本地授权、DIRECT 风险、有效期、本次启动及配置绑定，拒绝、超时、取消、重放和失效处理。
- [ ] **VPN Preflight/Prepare/Commit/Verify 启动事务。** 阶段推进、并发和幂等、取消、部分接管回滚、独立回滚失败及真实状态；检查和接管后验证通过前不得 Running。
- [ ] **App 完整主配置及启动 API 接入。** 接到 Rust 主配置/启动事务，保留当前 UI 布局，固定远程二进制并完成整合回归与打包。
- [ ] **网关模式。** 在已确认的 TUN/系统接管阶段后推进，完成转发、资源/生命周期、路由保护和真实部署验收。
- [ ] **完整 SOCKS/HTTP 代理入口。** 分别核实并补齐监听、认证、转发、失败后果、预算、取消和关闭；已有 HTTP/HTTPS/MITM 请求与部分代理功能不等于完整入口验收，也不能把所有 HTTP 能力误记为未实现。
