# Core 配置与资源只读迁移

2026-10-21。范围是 Core Rust、C ABI、模板、示例、测试和文档，不包含 App 接入或 UI、安装、打包。本轮不上传二进制。

## 最终职责

Core 只读消费宿主授权的现有配置和资源；不查询 App Group、HOME 或默认目录，不创建、修改、删除、覆盖、迁移、持久化或修复配置。插件、JS、规则和 MMDB 的下载落盘、更新调度、目录及来源权限由宿主承担。运行快照、规则编译、DNS／出站、QuickJS 缓存线程、取消和确定性关闭仍属于 Core。

保留 default_config.yaml／default_config_en.yaml 纯内容模板，默认 final,direct。指定不存在的默认节点必须报错，不能发布 VPN 候选或回退直连。新增字段／位置检查入口的唯一专项 API 文档见 [配置文件检查](API/配置文件检查.md)。编辑器依 UTF-16 偏移换算视觉行号；Core 不依窗口排版伪造显示行。

## 兼容变化

- 删除旧 storage_initialize、configuration_save；configuration_load 使用现有绝对 path，不再接受隐式 filename。能力位 30 撤销，位 31 声明只读文件能力。
- 新资源清单由宿主独立提供，不把配置 URL 当磁盘授权。规则／插件清单与启用声明对应；插件按唯一非零 ID 排序，主配置复写和 MITM 排除优先。
- provider_refresh／主配置 GeoIP 刷新明确 Unsupported；宿主更新后重新提交。状态 read_only=true，未执行的下载时间字段为 null。
- 规则 Store 使用内存更新和明确文件只读加载。二进制导出仅返回内存；不再创建目录锁、自动缓存或 YAML／SQLite 迁移。

这些开发接口变更依据用户明确的只读职责要求；旧客户端需配套迁移。正式错误代码、参数 Schema、规则匹配及拒绝策略不改号、不改义。回滚须客户端和 Core 二进制一起恢复，不能混用旧写入入口。

## 独立语义核对

已检查配置、资源、脚本绑定、规则缓存和 FFI 的文件操作调用链；剩余写操作是网络流和受认证 Debug 本地 IPC 套接字生命周期，不是配置／资源文件写入。Apple App Group 没有只读 entitlement，当前契约不声称 OS 已实施文件写隔离。

独立预期来自用户职责约束：缺失／损坏文件不得创建或修复，检查不得改变运行版本，错误更新不得部分发布；缺失默认节点不得直连；主配置优先插件；缺失 JS 排除对应规则，其他有效规则保留；取消与关闭等待真实操作／线程完成，旧 Arc 不占业务控制权。测试以这些输入及明确断言验证，不以另一套实现输出反推正确性。

## 测试迁移及历史保全

移除生产模块 platform/storage.rs、platform/providers.rs、providers/cache.rs，并同步退役同名测试及报告映射。这些旧测试针对自动创建、下载调度、目录交换、恢复日志、写锁和持久化，属于用户明确移除的行为；历史实现及原始报告保留在既有 Git 提交中，不把旧结果当作当前通过证据。

storage、providers、configuration/plugins、routing/store 的用例改为测试宿主先准备文件，Core 只读使用并核对文件内容／数量及失败保留。运行规则的独立策略、索引破坏、校验和重算、往返和预算断言继续保留；文件导出由明确命名的测试宿主 HostStore 负责，不向生产 Core 添加文件写入能力。原下载超时场景不再适用于候选资产准备；期限范围验证保留，真实准备总超时路径本轮不宣称完成独立覆盖。

每次实际测试以 tests 同名报告和对应原始日志为准。已有编译失败、沙箱回环 PermissionDenied、错误契约检查失败及重跑记录均保留，不用最后一次通过抹去先前失败。

## 验收边界

本机 Rust／回环／FFI 不能证明最低系统实际运行、真机、真实共享组签名、Network Extension 或系统 VPN。OS 授权仍由宿主正确取得；文件路径不替代来源认证。只读描述符能固定打开对象，宿主若需要多文件强一致版本，应提供准备完成的不可变版本化文件，再明确提交清单，不能边读边原地覆盖。

L1 以格式、严格 Clippy 和构建退出码为准；L2 以完整登记回归为准；L3 核对上述用户独立语义；L4 核对源码指纹、环境、提交、dirty 状态及原始退出码。构建、真实运行和发布分别记录，未测平台不冒充支持验收。
