# TUN DNS/Fake-IP 衔接

作者：可莉唯一的狗。新增功能版本：v2.2.0。地址池隔离修复交付版本：v2.2.1。

## 数据路径

完整 IPv4/IPv6 UDP/IP 包进入 `tun::udp::Session`。目标是显式 `dns_endpoints` 时，复用 `Resolver::respond`、上游缓存、DoH/DoT、DNSSEC、排除列表及标准 DNS 错误响应，生成交换源/目标的返回包。DNS 失败回应 SERVFAIL，不回退直连，不将失败解释为未命中。畸形请求回应 FORMERR；过大 UDP 响应按现有 EDNS 512–1232 字节预算返回 TC，保留 TCP 重试所需语义。

目标是本会话解析器合成池内的地址时，自动取所属解析器代次。共用出站恢复域名、真实解析候选地址，再执行既有域名优先规则及连接流程；不发送合成地址。域名命中动作后跳过 IP 规则的产品约定保持不变。没有域名命中时仍检查真实候选 IP 的保守拦截。返回包使用原合成地址作为源地址。

DNS 查询本身是本地解析服务，不把被查询域名作为 DNS 传输的目的地路由；它沿配置的 DNS 上游解析。查询得到的合成目标在连接阶段执行目标规则。全域 UDP 拦截仍拒绝虚拟 DNS UDP 请求。

## 接口与限制

C ABI 保持版本 1，使用现有二进制 submit/receive 及关闭入口；能力位 24。`tun_udp_open` 的可选 `dns_endpoints` 是最多两个数字 IP 端口（必须 53），默认空列表，未知字段拒绝。Swift 的 `NativeTunUDPClient` 对应 `dnsEndpoints`，仅传递值，不处理报文、映射或路由。

端点不得落入所配置的 Fake-IP 池，避免分配撞址。例如合成池 `198.18.0.0/16`、`fd00:198:18::/64` 时使用 `198.19.0.53:53`、`[fd00:198:19::53]:53`。主配置仍使用原 `dns` 字段；会话参数不新增主配置启用开关。完整中英文 YAML 注释包含调用示例。

会话创建时保留解析器 Arc。新 DNS/Fake-IP 请求只接受该解析器仍属于当前快照；替换解析器后明确拒绝，宿主需关闭并重开会话，同一进程的 TUN 池共用分配高水位，退役地址不能在新会话重新解释为其他域名。普通 API 的历史分配也计入高水位；接管后的同范围普通查询共用安全游标，外来解析器地址仍不能用于本会话。最多同时登记 16 个存活池，注册表只持有弱引用，最后一个绑定解析器释放后回收占用；不同存活池的 IPv4 或 IPv6 范围重叠时仍拒绝绑定。退役池不阻止配置区间变更：IPv4 用覆盖 198.18.0.0/15 的 16 KiB 固定位图记录已分配地址，IPv6 使用最多 4096 个可合并的已分配区间，首次登记前从既有 16 MiB 映射预算预留 256 KiB。历史记录不保存域名，且不随解析器释放；新 TUN 分配同时跳过任一地址族的已分配地址，碎片区间额度或地址耗尽返回资源错误。该额度限制实际地址历史的碎片数，不按历史配置数量计数。池地址耗尽明确报错，不回绕。已有普通 API 映射的解析器不能直接转换为 TUN 池，需创建新解析器。跨进程不持久化高水位，后续系统隧道生命周期必须隔离旧缓存/旧流，不能声称跨重启安全已验收。旧会话已有 UDP 流继续使用其已检查的真实对端；关闭时全部取消。规则更新而解析器所有者未变时，新流采用新路由快照，旧流保留原策略。映射清除后新流拒绝旧地址，同实例不复用已分配地址。

每会话一个提交在途，最多 8 会话；DNS 查询复用全局 16 查询预算，不逐包新建任务。先占用有界输出槽，再查询/分配；满队列立即返回配额错误。Fake-IP 每解析器最多 4096 条，映射全局预算 16 MiB、输出包全局 4 MiB；资源上限未增加。close 取消进行中的查询与连接，不停止共享 Manager，不保存宿主指针。

## 验证范围

专项 Rust 测试覆盖真实上游、IPv4/IPv6 DNS 包、合成查询不触及上游、Fake-IP 到实际 IPv6 UDP 对端再返回原合成地址、映射清除、解析器同池换代、FORMERR/NXDOMAIN/SERVFAIL、背压、配额、错误所有者代次、端点碰撞、UDP 拦截、取消、普通包与重开。

独立 Swift FFI 构造 IPv4 包，验证合成响应、无需宿主代次的真实 UDP 转发、配置替换拒绝、关闭及 40 次资源回收。App 必须另用已发布二进制复验；发布来源和最终结果在交付记录补充。

TCP DNS 入站、TCP TUN 流、分片、系统 Network Extension 尚未交付。大响应 TC 后的 TCP 请求明确 Unsupported，不能宣称所有 DNS 流量可用。没有实际系统 VPN、最低 macOS 14、Intel 或其他平台运行验收。本阶段不修改系统设置、不新增日志通道。
