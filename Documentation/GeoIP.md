# 离线 GeoIP 与网络测量

作者：可莉唯一的狗。

v1.7.0 提供 MMDB 读取、IPv4/IPv6 查询、节点域名通过配置 DNS 获取真实地址、固定公网 IP 回显，以及节点 TCP 建连耗时 API。C ABI 保持 v1，能力位 20 表示 GeoIP。

数据库由宿主提供，只读加载，不写入配置，不打包进 crate。采用 maxminddb 0.32.0，关闭默认 mmap 与 unsafe 字符串功能；业务代码不使用 unsafe。单库最多 256 MiB，全局数据库配额 512 MiB，替换新库失败保留旧库；读取只提取国家代码、城市和省州名称，每个字段最多 100 字符，地址最多 64 字节、语言最多 16 字节。查询不复制整个记录，不返回坐标或设备标识。

默认不指定在线归属地平台。宿主可使用免费 DB-IP Lite City 月度数据库，需保留 CC BY 4.0 署名；数据质量不能等同于精确物理位置。示例测试数据库为自有生成数据，并非真实地理定位。maxminddb 与 ipnetwork 上游声明保存在 Notices/，完整传递依赖分发审计仍需单独核实。

公网检测仅访问 https://api.ipify.org/ 和 https://api6.ipify.org/，分别校验 IPv4/IPv6 响应。复用 Rust HTTPS、配置 DNS 和出站流程，响应正文最多 64 字节，整体超时 10 秒，不跟随重定向。服务获知请求公网来源，不发送节点地址、凭据或调试正文；宿主负责初次总体隐私披露。无 IPv6、网络故障、DNS/TLS 错误必须展示未获取，不捏造地址。

TCP 测量复用共用出站连接管理，成功后立即释放，不发送应用数据，不等于 VLESS/REALITY 握手验证。域名测量包含配置 DNS 查询时间；数字地址不解析 DNS。旧协议、路由和系统 TUN 能力范围不因首页或 GeoIP 增加而改变。

本次未新增用户 YAML 配置字段；DNS 来源沿用已有 dns 字段，宿主未导入时可通过 Apple 公开系统适配取得解析器地址传入内核，内核不自行强制替换为公共 DNS。
