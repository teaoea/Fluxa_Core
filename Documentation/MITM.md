# 第二项：MITM

HTTPS 阶段已先测试并单独上传；本阶段在其基础上实现 Rust CONNECT 入口、客户端侧 TLS、站点证书签发和请求/响应日志。共用 HTTPS 客户端、HTTP 分帧、错误、资源注册表、字节预算与 Swift FFI 门面，不重新写转发流程。

## 功能行为

监听默认且仅为 `127.0.0.1`，端口 0 由系统分配。调用方显式提供最多 128 个精确域名或 IP；支持大小写与单个末尾点规范化，拒绝通配符。未匹配域名使用加密 CONNECT 透传，不签发证书或捕获明文。当前不开放 LAN 监听、不设置系统代理或网关，也不修改证书信任。

匹配域名先建立上游 TLS，使用系统或调用方明确提供的根证书校验签名、域名与有效期；失败向 CONNECT 客户端返回 502，禁止伪报成功或回退直连。验证后生成站点证书，接受客户端 TLS。客户端需要明确安装信任公开根证书；不绕过固定证书校验。

HTTP Host 必须与 CONNECT 目标的主机和端口一致，TLS SNI 不得指向不同主机。拒绝未知协议、绝对 URI、Upgrade、Expect、歧义消息边界和未实现 trailers。请求/响应最多 8 MiB，头最多 32 KiB/128 项；只处理一组 HTTP/1.1 请求与响应后关闭连接。支持 chunked 解码、HEAD 与保留重定向。HTTP/2、HTTP/3、WebSocket、双向 TLS、透明代理、脚本改写与分流规则后续实现，不视为本阶段已支持。

## 证书与平台存储

Rust 使用 rcgen 生成独立的 ECDSA CA，根证书有效期约 3 年，路径长度限制 0；站点证书只包含目标 SAN，有效期最多 7 天且不超过根证书到期日，具有 ServerAuth EKU。

普通证书接口仅返回公开证书。私钥仅由明确的安全存储接口返回，调用方必须使用平台钥匙串等安全存储，不得分享、写入日志或加入仓库。Rust 内部的密钥导出临时值、FFI 响应缓冲区和日志正文在释放时尽力清零，不保证所有密码库内部副本或 Swift 字符串均已可靠擦除。当前未修改 UI，Apple 钥匙串接线尚未完成；不能宣称新 Rust CA 已自动持久化。

支持恢复 CA：校验 CA 约束、有效期、自签名及证书与私钥一致性；失败保持既有证书，不静默重新生成。代理运行时禁止恢复 CA 或替换上游信任配置。

## 捕获、上限与停止

正文捕获默认关闭；开启后记录完整的受支持正文、头、方法、URL、状态、时长及明确错误。请求头为客户端原始头，响应头为上游原始头；正文去除 HTTP chunk framing，保留可能存在的内容编码。未捕获正文仍记录实际长度，调用方不得将空日志正文显示为原请求没有正文。

每实例队列最多 64 条/32 MiB，所有实例合计最多 64 MiB，超限淘汰本实例旧记录或拒绝新记录，并提供累计丢弃计数。使用 peek + acknowledge，只有客户端成功解码并确认后才删除记录；FFI 分配或复制失败不会消费记录。FFI 单份输出最多 24 MiB，待复制输出总量最多 32 MiB。

全局最多 8 个活动 CONNECT 会话，每会话最多 60 秒。显式 stop 取消全部会话、等待任务结束并释放监听；停止幂等。对象销毁发送取消作为兜底，不依靠析构等待网络。没有任何业务模块 unsafe，新功能复用既有 FFI 的两个必要内存边界。

## 客户端与验收

当前 Swift 归属、旧检查脚本状态及二进制接入见 [Swift 适配与验证](Swift适配与验证.md)。

`NativeMitmClient` 通过实际 C ABI 提供：根证书、导出/恢复安全存储身份、设置上游额外根、启动、停止、peek 日志与 acknowledge。`NativeHttpsClient` 可经本机 CONNECT 端口发起 HTTPS，所有网络和 TLS 在 Rust 内执行，无失败直连回退。内部 JSON 只用于 ABI，用户配置仍使用 YAML。

```sh
python3 Tools/test_reports.py --run --evidence-dir /private/tmp/nodus-local-tests
cargo clippy --manifest-path ./Cargo.toml --offline --all-targets -- -D warnings
bash ./build-macos.sh
```

2026-10-09，macOS ARM64 主机：Rust 验证真实双向 TLS、完整请求/响应捕获、关闭正文捕获、未匹配域名保留原证书、上游和下游证书拒绝、跨 Host 拒绝、chunked 请求、HEAD/重定向、CA 恢复、错配私钥拒绝和停止关闭活动连接。Swift 实际客户端 FFI 验证启动、请求、日志读取/确认、信任与 CA 身份、重复启动拒绝、停止幂等、停止后不回退直连。HTTPS 阶段一并回归。另通过 macOS ARM64 Release XCFramework 实际链接的 Swift package 身份恢复测试。

当前不改 UI，未执行最低系统、真机、真实浏览器配置或 App Store 审核。测试只运行回环服务，根证书不安装系统，私钥不落盘，临时输出退出后清理。

## 共用服务连接管线（v1.3.0）

HTTP/HTTPS/MITM 已统一使用配置 DNS、实际路由和受管理连接；取消、空闲回收及资源所有权均沿用共用管线。未配置能力明确拒绝，TLS 信任与域名解密范围不改变。实现、发布来源及完整验证边界见 [Outbound.md](Outbound.md)。
