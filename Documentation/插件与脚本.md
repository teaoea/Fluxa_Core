# 声明式插件与 JavaScript

作者：可莉唯一的狗。适用于本轮 dev 源码；发布附件与提交以最终交付记录为准。

## 字段与示例

插件正文只接受 `mitm`、`rewrites`、`scripts`，缺省为空；拒绝未知字段、重复键、null 脚本对象、标签和别名。插件不能携带正式路由、节点、Debug 或宿主权限。插件不能自行跳过服务器证书验证或开启正文捕获。主配置中的 `plugin-providers` 继续采用 name/category/url/enabled/update-time；URL 必须 HTTPS，每个来源名称唯一，时间使用设备本地 HH:mm，省略时只在首次导入或明确手动刷新时下载。

```yaml
mitm:
  enabled: true
  hosts: [api.example.com]

rewrites:
  - url: https://api.example.com/user/**
    phase: response
    when:
      status: 200
      content-type: application/json
    action: script
    js: response
    js-ttl: 3600

scripts:
  name: response
  url: https://example.com/response.js
```

`scripts` 是一个对象，不接受数组；name 必填、1–128 字节安全 ASCII 名称，不接受路径、URL、源码、隐藏名称或目录穿越。`rewrites[].js` 必须与 name 精确一致，区分大小写；名称允许没有 .js 后缀，URL 文件名与引用键无关。url 可省略，此时只能引用已由用户放在约定目录的同名本地文件；给出 url 时必须为无凭据 HTTPS。主配置和插件使用同一格式。`js-ttl` 只允许 action: script，必须为正整数秒，省略 3600；JS 注释中的 TTL 不再作为配置读取。

## 存储与事务

主配置资源保存为平台返回的真实系统共享容器 `js/<name>`（macOS 使用实际签名团队的 `<TeamID>.app.fluxa.shared`，iOS 保留 `group.app.fluxa.ios`），插件资源为 `plugin/<数字ID>/<name>`；远程正文保存为该插件目录的内部 `.plugin.yaml`。每次编译重新查询系统容器，不从 HOME、环境变量或任意目录猜测。目录表只保存内部资源摘要和调度记录，名称不作为 ID；新来源从历史最大 ID 加一。重新排序时交换对应 ID、目录与优先级，已移除来源保留目录和历史 ID，不挪用其身份。禁用项不下载、不执行。

内核先在私有候选目录下载、严格解析并绑定，再与配置快照一起发布；目录交换或规则缓存提交失败时回滚候选，保留已发布配置。两个资源目录使用持久化代次标记和更新记录：恢复时回滚单边交换，完整双边交换作为已下载缓存复用；不因此恢复或宣称 VPN Running。恢复夹具覆盖持久化状态，真实断电耐久性尚未验收。只读扩展和未发布 VPN 候选复用已完成的本地资源，不下载、不创建目录、不修改目录表，也不能通过配置顺序伪造已完成的目录换序。读写编译使用不参与交换的协调锁。

资源及目录拒绝符号链接和非普通文件。插件正文最多 1 MiB、脚本最多 256 KiB，受限下载在读取时执行对应上限；候选资源总量 16 MiB、独立全局资源预算 128 MiB，插件解析另预留 64 倍输入与 64 KiB 固定开销。达到上限明确拒绝，不以文件数量上限保证任意大小都可准入。目录表最多保留 128 个历史来源；超限不覆盖旧目录。

编译结果保存绝对路径、目录/只读文件身份和不可变规则，不包含 JS 正文。脚本源码到命中并执行时才读取。发布时固定文件身份，保证目录换序/清理后已开始的旧快照仍能读取原来源；缓存清理后当前目录重新读取文件，旧代次使用已固定的文件身份。

名字未登记、不匹配或脚本文件不存在时记录受控错误，排除相应脚本复写；其后的有效规则仍能匹配。插件正文结构错误使本次更新失败并保留已发布版本。脚本下载失败记录错误并排除依赖脚本的规则；不把旧 URL 的同名资源冒充新下载成功。脚本执行异常、超时、取消或输出非法直接返回错误，不默认 Continue、DIRECT 或伪造成功。

## 优先级与解密边界

每阶段先主配置的有效规则，再插件 ID 升序，每个来源保持声明顺序；第一条 URL 与 when 都匹配的有效规则生效。未绑定脚本不占据这一位置，裸 proxy 继续忽略。同名脚本不跨主配置与插件或跨插件读取。

主配置 MITM 总开关和 bypass 优先；插件声明不能覆盖主配置禁止解密的目标。匹配复用主配置的域名/通配符边界，不另造更宽泛的范围。Manager::mitm_matches 查询已发布的合并范围；范围命中不代表 CA 已受信任、监听已启动或 VPN 已运行。完整主配置启用 MITM/监听仍明确返回 Unsupported；既有显式调试代理也执行主配置 bypass。不得把本节范围判断或回环测试视为系统 MITM 验收。

## JS 输入、输出与隔离

引擎为已固定版本 rquickjs/QuickJS，源码是同步函数表达式，例如 `(input) => ({body: input.body.replace("ad", "")})`。不运行 Promise 作业队列，不提供网络、文件、模块加载或宿主资源句柄。每次执行创建独立运行时与上下文，不跨请求保留 JS 全局变量。

请求阶段输入为 `{method, url, headers, body}`，headers 是 `{name, value}` 数组，body 是 UTF-8 字符串。响应阶段输入为 `{status, headers, body, request}`，request 是本次原始请求的上述结构。响应阶段必须先获得真实服务器响应并通过 when，不能提前构造响应冒充上游。

输出是只包含变更字段的对象，也可回传未修改输入。请求输出允许 method/url/headers/body；URL 必须保持原来源，禁止跨来源、凭据、片段、控制字符或反斜杠。响应输出允许 status/headers/body；如回传 request，必须保持原值。未知字段、字段类型错误、非法最终状态、受保护头篡改或注入均拒绝。替换正文清除失效的压缩、范围、长度与完整性头；写出层重新分帧。输入不支持自动解压或二进制 JS body，压缩正文明确拒绝。

```javascript
// response 资源的完整同步函数；没有缓存生命周期头注释。
input => {
  const data = JSON.parse(input.body);
  delete data.ad;
  return {body: JSON.stringify(data)};
}
```

源码最多 256 KiB，输入/输出 JSON 各 1 MiB，深度 64、节点 16384；运行时堆 32 MiB、执行最多 250 ms，最多四份全局运行时/工作线程配额，每线程有界排队。源码、输入及排队另有预算；预算不等于进程 RSS 上限。输出经内核重新校验，不能取得路由、存储、取消令牌或线程权限。

每个命名资源使用独立工作线程，同一资源被不同 TTL 规则引用时共用最短 TTL。到期标记停止接收新任务，等待在途执行自然结束后释放；手动清理会中断在途 QuickJS、拒绝排队任务并 join 实际线程。容量不足只淘汰无排队且无在途执行的闲置线程，不能依靠创建同一资源的新线程绕过待移除状态。

Rust 使用 `Manager::clear_script_cache().await`。C ABI 使用 `{"operation":"script_cache_clear"}`；成功回复表示实际清理已完成。关闭管理器也必须中断、join 后才能报告关闭完成。脚本失败不污染下一次独立执行。

## 验证边界

对应源码、测试与同名报告位于 tests/test_configuration_plugins、test_script_worker、test_outbound_configuration 和既有复写管线测试。临时私有目录夹具仅验证内部绑定和文件事务，不冒充真实 App Group。实际本机 TLS 测试验证请求/响应修改；真实 Swift FFI、完整回归、发布来源与附件校验分别记录，编译或局部通过不能代替其他验收。系统 VPN、完整主配置 MITM 启动、真机客户端去广告效果、最低部署系统运行及其他平台仍需要独立验证。
