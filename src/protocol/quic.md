# quic.rs 代码说明

## 职责（干嘛的）

对应源码：`src/protocol/quic.rs`。本页说明实现职责、数据流程和边界；公开调用的请求／响应契约单独维护于 `Documentation/`，开发约束维护于 `AGENTS/`。

## 目标（想达成什么）

为 UDP 数据面提供有界 QUIC 形状识别，区分普通 UDP 与需拦截的 QUIC 流量。

## 主要流程与模块协作

解析受支持版本的长头、CID、Token／Length 及首包边界，识别结果由出站／TUN 规则保护使用；报文形状不是密码认证，未观察到握手的短头与迁移不伪称全覆盖。

## 输入、输出与失败边界

输入来自受约束的配置、明确授权的资源或校验后的网络数据；各入口的实际类型、字段和值域以下文及对应源码为准。正常结果只能说明该模块完成其职责，不能推定网络接管、其他模块初始化或外部权限已经成功。非法输入、协议错误、系统故障、取消和资源不足沿用 `src/error.rs` 的真实分类；不静默改为 DIRECT，也不修复或覆盖外部配置。

活动资源由 Core 的会话身份、有效租约、取消及明确关闭操作管理；只读快照引用不构成活动权限。内存与任务的实际存活期计入对应预算。具体模块没有活动任务时，不因本说明增加后台线程或额外权限。

## 实现细节

作者：可莉唯一的狗。

沿用新规则架构、具名类别、独立优先级和二进制规则缓存。TCP/UDP 使用现有直接索引；新增 QUIC 是 UDP 数据面检查，不能把它当成第三种物理传输或给规则类别增加最高优先编号。编译时从生效规则生成一个布尔拦截标志，缓存加载也从校验后的生效文档恢复。每次请求不扫描规则、不解析 YAML、不新增任务或堆分配。

```yaml
rules:
  - type: transport
    value: quic
    policy: reject
```

value 可替换为 tcp 或 udp，动作只允许 reject；UDP 拦截同时拦截 QUIC。QUIC 拦截保留普通 UDP，包括普通 UDP/443；不依赖目标端口。所有 enabled 来源采用同一生成实现；重复拦截合并，不能被直连或代理覆盖裁剪。旧域名/IP/端口类别优先级保持不变，临时 Debug Overlay 独立于正式类别；QUIC 数据面保护不能用调试动作绕过。调试会话不接受独立 QUIC 规则，明确返回不支持。

Rust 接收和发送 UDP 报文都使用同一检查函数，涵盖直接 UDP、REALITY/XUDP 与 TUN UDP。发送被识别 QUIC 前拒绝，接收被识别 QUIC 后不交付正文，关闭该连接。新连接固定新配置，存量连接保留原快照。只保存一个连接内识别位，随连接取消、关闭或空闲回收释放；不增加无界 CID 字典。

识别支持 RFC 9000 的 QUIC v1 和 RFC 9369 的 v2 长头、有限 CID 长度、Token/Length 变长整数、首个包的边界；尾部填充和合并包不撤销首包识别，避免追加字节绕过。已观察到长头的同一连接后续报文属于关联流；未观察握手的独立加密短头、迁移到新 UDP 连接、未支持版本、清零 Fixed Bit 和不可解析的形状是明确边界。报文形状不是密码认证，不声称识别所有 QUIC 或阻止恶意流量伪装；需要阻断所有 UDP 时应配置 udp 拦截。

验证使用真实 UDP 对端检查普通报文到达、QUIC 拒绝后无应用报文到达、规则移除/存量连接、新旧快照、来源去重、二进制缓存恢复；单元测试包含 v1/v2、截断、非法 CID、短头关联、合并和 0–9000 字节异常输入。真实 Swift FFI 与固定独立 REALITY 服务端验证同一数据面。额外用固定 aioquic 1.2.0 生成真实加密的 1200 字节 Initial，作为识别测试输入；仅为测试工具，不链接或分发进内核。

最低 macOS 14 实际运行、Intel、其他 Apple 平台、完整 HTTP/3 应用、QUIC 迁移和系统 VPN 未测。未新增日志功能。

可运行 Rust 示例：cargo run --example protocol_block；只编译规则和识别测试向量，不连接外部目标。

发布前验证：181 项 Rust 测试、严格 Clippy 和 14 组真实 Swift FFI 通过，包括独立 aioquic 1.2.0 加密 Initial 拦截；业务模块无新增 unsafe。最终独立 REALITY 服务端按现有 37 组指纹/套件矩阵复验。早先本地互通出现一次 30 秒超时，未确定原因，最终源码完整矩阵重新执行，记录实际结果，不以普通报文测试替代 HTTP/3 应用验收。

## 禁止行为（不允许做什么）

不得仅凭 UDP/443 判断 QUIC，不能把未观察握手的短头、跨流迁移或不支持版本伪称已识别，不维护无界跨连接 CID 字典。

违反输入、授权或资源边界时，使用实际模块的既有错误／拒绝路径，不伪造成功或擅自扩大权限；具体失败后果以上文流程和公开契约为准。
