# mod.rs 代码说明

## 职责（干嘛的）

对应源码：`src/dns/mod.rs`。本页说明实现职责、数据流程和边界；公开调用的请求／响应契约单独维护于 `Documentation/`，开发约束维护于 `AGENTS/`。

## 目标（想达成什么）

根据明确配置解析真实地址或分配所属解析器的 Fake-IP，拒绝将解析错误当作直连许可。

## 主要流程与模块协作

Resolver 统筹配置、查询、缓存与关闭；config／wire 校验输入，runtime 管理任务和准入，service 处理受控 DNS 服务，fake_ip 维护带会话身份的映射。

## 输入、输出与失败边界

输入来自受约束的配置、明确授权的资源或校验后的网络数据；各入口的实际类型、字段和值域以下文及对应源码为准。正常结果只能说明该模块完成其职责，不能推定网络接管、其他模块初始化或外部权限已经成功。非法输入、协议错误、系统故障、取消和资源不足沿用 `src/error.rs` 的真实分类；不静默改为 DIRECT，也不修复或覆盖外部配置。

活动资源由 Core 的会话身份、有效租约、取消及明确关闭操作管理；只读快照引用不构成活动权限。内存与任务的实际存活期计入对应预算。具体模块没有活动任务时，不因本说明增加后台线程或额外权限。

## 实现细节

作者：可莉唯一的狗。

v0.4.0 提供 UDP/TCP、DoT 和 HTTP/2 DoH 查询。UDP 截断回复改用同一上游 TCP；多个上游按配置顺序切换，每项独享所配置的超时期限。底层 Config 列表不混合加密与明文；新主配置 server 通过独立端点支持混合，错误证书、错误域名和 DNSSEC 验证失败不降级。bootstrap 必须使用数字 IP 和端口，不使用系统 DNS/hosts。

支持 A、AAAA、CNAME 和标准记录查询；拒绝 ANY、AXFR、IXFR、OPT 和未知类型。正缓存最多一小时；NXDOMAIN/NODATA 使用 SOA 的 TTL/minimum，最多五分钟。每个实例最多 128 条缓存，全局预算 16 MiB，每条预留 128 KiB；全局最多 16 个客户端和 16 个在途查询，超过上限拒绝。查询总期限 100–30000 毫秒，上游 1–8 个。显式关闭立即撤销权限并等待资源清理；配置替换采用下述退休流程，不取消已准入事务。

DNSSEC 使用 Hickory 签名和信任链验证及内置根锚；Rust 私有部署可显式提供根锚。安全状态 secure、insecure、disabled；AD 标记不能代替验证。不可信根、篡改和过期签名拒绝返回答案。已验证的否定结果只按验证后的 SOA/NSEC 有效 TTL 缓存。

## YAML 配置

App 主配置采用 dns 字段；timeout-ms 默认 5000、dnssec 默认 false。

```yaml
dns:
  timeout-ms: 5000
  dnssec: true
  servers:
    - transport: doh
      url: https://cloudflare-dns.com/dns-query
      bootstrap: 1.1.1.1:443
```

udp/tcp 使用 address（IP:端口）；dot 使用 address、server-name；doh 使用 url、bootstrap。IPv6 地址带方括号。URL 禁止凭据和 fragment，bootstrap 端口必须与 URL 一致。配置保存不触发查询；用户执行查询时，域名会发给所选服务商。

## 验证与边界

真套接字测试覆盖四种传输、CNAME、AAAA、TXT、截断、正负缓存和到期、上游切换、证书信任和域名、事务编号、超时恢复。签名根区域测试覆盖合法、篡改、过期、不可信根与 NSEC 否定证明。真实 Swift FFI 覆盖四种传输、缓存、关闭、100 次释放及不信任 AD 标记。不修改系统信任或 DNS 设置。

Fake-IP 与局域网 DNS 服务已分别实现，详见下文。未实现 DoQ/HTTP3、权威 DNS、mDNS 或根锚自动更新。HTTP 调试服务现有系统域名解析将在共用出站阶段接入本模块。查询能力不代表 TUN、网关或系统代理已可用。仅发布 macOS ARM64 切片；最低部署系统及其他平台尚未运行验证。

## Fake-IP（v0.5.0）

DNS 配置可增加 fake-ip。A/AAAA 返回合成地址，其他记录类型与排除域名使用所选真实上游。合成结果的验证状态明确为 synthetic，不代表原始域名签名验证成功，也不会被标记为 DNSSEC secure。

```yaml
fake-ip:
  ipv4-range: 198.18.0.0/16
  ipv6-range: fd00:198:18::/64
  capacity: 4096
  exclude:
    - localhost
    - local
```

IPv4 范围限 198.18.0.0/15 的对齐子网，前缀 15–30；IPv6 限 fd00::/8 的对齐子网，前缀 64–120。容量 1–4096 且不得大于可用地址。域名大小写、末尾点统一归一化；排除项按域名标签边界匹配。映射保留到显式重置/关闭，不按响应的 60 秒 TTL 自动淘汰。正反向查询、A/AAAA 共享域名编号；反查不存在返回空值，输入错误或未启用则明确拒绝。

同一实例重置后只清除映射，不倒退地址游标，旧地址不会分配给其他域名。地址池耗尽后拒绝分配；全局映射预算 16 MiB，每条预留 1 KiB，关闭与重置归还预算。关闭或替换配置创建新实例可能重新使用地址，因此调用者必须先停止使用旧池的流量；当前没有把映射直接接到系统 TUN 或网关。

Rust 测试覆盖稳定双向映射、IPv4/IPv6、排除边界、容量/范围/地址池耗尽、重置不复用、并发分配、排除项真实解析、合成查询不联系上游及不伪造 DNSSEC。真实 Swift FFI 覆盖配置、A/AAAA、反查、容量拒绝、重置与关闭。TUN/路由/出站接入仍为后续任务。

## 局域网 DNS 服务（v0.6.0）

服务复用客户端的显式上游、正负缓存、DNSSEC 和 Fake-IP，不另建解析规则。仅支持递归转发，不提供权威区域、区域传送、mDNS 或迭代解析。配置校验不监听端口，调用 serve/显式启动才监听；同一端口同时支持 UDP 和带长度帧的 TCP，端口 0 用于系统分配。

```yaml
service:
  listen: 0.0.0.0:5353
  allow-lan: true
  allowed-clients:
    - 192.168.1.0/24
```

默认 127.0.0.1:0，仅本机可访问。局域网监听必须显式启用并提供 1–32 个对齐 CIDR；仅接受私有、回环或链路本地范围，拒绝公网及全网访问，IPv4 映射 IPv6 客户端按 IPv4 校验。不自动修改系统 DNS、路由器、防火墙或系统信任。固定监听 53 端口所需权限由宿主处理。

全局最多 4 个服务、16 个 TCP 连接及 16 个在途服务请求；单服务最多 128 个近期来源，每来源每秒最多 32 个问题。输入 12–4096 字节，单 TCP 会话总期限 60 秒、等待问题 15 秒、正文读写 5 秒。计数区分已接受与拒绝问题，不表示上游成功数。UDP 输出默认 512 字节，EDNS 最高 1232 字节，大响应返回 TC，客户端可重试 TCP；TCP 输出最高 65535 字节、最多 256 条记录。

保留请求编号和问题，过滤不支持的附加记录/TSIG，拒绝非 IN、非递归、ANY 和区域传送；错误返回 FORMERR/REFUSED/NOTIMP/SERVFAIL，EDNS 版本错误返回 BADVERS。AD 只对本地验证 secure 且客户端请求 AD/DO 时设置；合成 Fake-IP 不设置 AD。CD 不绕过服务端强制 DNSSEC 策略；非 DO 请求省略未显式查询的 DNSSEC 证明记录。这里没有实现 TSIG 身份认证，CIDR 访问范围不是密码学认证。

C ABI 提供 dns_service_start/stop/status；运行中重配置明确拒绝。停止等待监听与连接子任务退出，关闭 DNS 一并停止服务；Drop 发取消作为异步兜底。Rust 不持有跨等待的 FFI 注册表或配置锁，业务没有新增 unsafe。端口冲突、服务配额及取消路径均归还资源。

验证覆盖真实四种上游到下游 UDP/TCP、CNAME/NXDOMAIN、EDNS/大响应截断和 TCP 重试、DNSSEC 好/坏签名、Fake-IP 无 AD、CIDR 拒绝、速率限制、IPv6、停止持久/空闲连接、绑定失败清理、Drop 与全局配额。独立系统 dig 客户端验证 UDP/TCP Fake-IP 互通。真实 Swift FFI 另测启停、状态、关闭、配置拒绝和重复生命周期。其他物理局域网设备、最低 macOS 14 运行和其他平台未验收；此服务能力仍不代表网关或 TUN 转发已实现。

本机发布前检查：62 项 Rust 测试、Clippy -D warnings、SwiftFormat/SwiftLint 严格检查通过；七组真实 Swift FFI 通过，服务组含 20 次启停/关闭及系统 dig UDP/TCP 互通。运行环境为 macOS ARM64；发布后的 CI、版本来源与校验值另行记录。

## 错误协议示例与失败边界

有效解析器的 `Resolver::respond(&[], true)` 返回标准 FORMERR 报文，这是 DNS 协议负响应，不是错误默认放行；退休或关闭实例先返回 `Error::InvalidState`（9001），不能继续提供 FORMERR 服务。构造响应的编码失败返回 `Error::DnsResponse`（5002），无回复上游超时使用 `DnsTimeout`（5001），统计锁中毒使用 `Internal`（9901），系统明确报告内存不足使用 `ResourceLimit`（8001），静态字节预算准入失败使用 `ResourceBudgetExceeded`（8002）。不得返回空报文伪造成功。当前代码与参数契约以 `src/error.rs` 和 [错误代码查询表](../../Documentation/API/error_api.md) 为准。实际测试及同名报告通过 `python3 Tools/test_reports.py --run --suite test_dns_mod --suite test_dns_service --suite test_error_contract` 更新。

## 解析器配置替换与退休（F-01）

`Manager::configure_dns()`、`configure_network()` 和 `configure_network_with_outbounds()` 统一在网络配置锁内提交。全部输入、节点、限额与新解析器状态验证成功后，关闭被替换解析器的查询准入，再发布新快照；复用同一解析器的路由或限额更新不会触发退休。失败提交保留旧配置和旧解析器权限。

“退休”与“显式关闭”是不同的操作：

| 操作 | 新查询/新建连 | 已准入查询及建连事务 | 已建立业务连接 | 完成边界 |
| --- | --- | --- | --- | --- |
| 配置替换触发退休 | 旧解析器返回 9001，新事务使用新快照 | 由内核作用域令牌保留权限，在原有超时内完成 | 继续读写，不随 DNS 更新关闭 | 同步配置返回表示快照已发布和旧准入已关闭；后台排空事务后停止监听/驱动并归还活动解析器名额 |
| `Resolver::close().await` | 拒绝 | 立即撤销、取消并等待退出 | 不直接拥有业务 Socket；会话关闭仍由其归属权限管理 | 监听、查询、驱动和活动实例配额完成释放后返回 |
| `drop(Arc<Resolver>)` | 不能充当关闭或退休命令 | 不以引用计数决定业务权限 | 不裁决业务连接状态 | 只减少对象引用；析构兜底不能代替显式生命周期流程 |

解析器分别使用查询准入 Authority 和驱动 Authority。退休只先关闭准入；内核内部 `ResolverOperation` 令牌绑定不可复用身份，覆盖整个已准入建连事务，包括目标解析、必要的代理节点解析、拨号及提交。普通查询自行登记短期令牌。退休后不能通过旧快照、旧引用或其他解析器的令牌创建新操作；显式关闭仍通过驱动 Authority 取消所有在途操作，不能用退休令牌绕过会话撤销。

清理由内核运行时托管，调用方丢弃旧快照或取消等待都不是释放活动资源的前提。DNS 监听任务持有解析器引用，因此退休/关闭必须主动停止服务、打破资源持有环；仅修改 `Drop` 并不能解决监听任务阻止析构的问题。析构仍执行停止已登记服务和驱动的兜底清理。

全局 16 个名额限制的是尚未完成清理的活动解析器，不是仍被外部持有的元数据对象。排空尚未完成时名额仍占用，连续快速创建超过真实活动上限仍允许受控返回资源错误；禁止提前归还配额或伪称资源已释放。旧对象保留的配置、缓存、Fake-IP 元数据及其实际内存预算继续随真实所有权存活。

本次未新增配置字段、公开错误代码或 C ABI 命令，不改变规则优先级与出站策略。可运行示例见 `examples/dns_retirement.rs`；回归覆盖见 `tests/test_dns_mod.rs` 和 `tests/test_outbound_dns.rs`，执行结果以同名报告为准。系统 VPN、局域网攻击压力及跨平台行为不由这些回环测试代替。

## 新主配置编排（2026-10-17）

server 的显式 direct/节点出站不受业务规则改写；bootstrap 仅服务 DoH/DoT 及 DNS 所用节点域名。显式 system 才参与业务 DNS 列表，全部超时不自动回退。hosts 优先于 Fake-IP，DNS 关闭两者均停用。实现与生命周期、地址族和错误边界见 [DNS/GeoIP 编排](main.md)。关闭先停止专用节点连接，再等待权限操作归零；旧 Arc 不决定资源释放。

## 禁止行为（不允许做什么）

不得将解析超时、响应校验失败或资源拒绝改成允许直连；旧解析器不得在身份撤销后继续申请网络资源，合成地址不得冒充真实 IP。

违反输入、授权或资源边界时，使用实际模块的既有错误／拒绝路径，不伪造成功或擅自扩大权限；具体失败后果以上文流程和公开契约为准。
