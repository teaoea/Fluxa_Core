# traffic_script.rs 代码说明

## 职责（干嘛的）

对应源码：`src/traffic_script.rs`。本页说明实现职责、数据流程和边界；公开调用的请求／响应契约单独维护于 `Documentation/`，开发约束维护于 `AGENTS/`。

## 目标（想达成什么）

提供受限的内置 JSON 顶层键移除动作，保持未命中数据及非目标字段的语义。

## 主要流程与模块协作

Script 严格校验动作和键集合，只处理允许类型和大小的 JSON 对象；变更后由复写管线移除失效实体校验头并重新分帧，不将任意资源 URL 当作内置动作源码。

## 输入、输出与失败边界

输入来自受约束的配置、明确授权的资源或校验后的网络数据；各入口的实际类型、字段和值域以下文及对应源码为准。正常结果只能说明该模块完成其职责，不能推定网络接管、其他模块初始化或外部权限已经成功。非法输入、协议错误、系统故障、取消和资源不足沿用 `src/error.rs` 的真实分类；不静默改为 DIRECT，也不修复或覆盖外部配置。

活动资源由 Core 的会话身份、有效租约、取消及明确关闭操作管理；只读快照引用不构成活动权限。内存与任务的实际存活期计入对应预算。具体模块没有活动任务时，不因本说明增加后台线程或额外权限。

## 测试与示例入口

相关测试按 `Tools/test-suites.json` 的实际源码映射核对，不以缺失的同名文件声称覆盖。

性能结果及执行记录保存在对应测试文档；下文涉及旧版本的验证陈述仅是历史资料，不是本次重新执行的结果。已发布版本的历史能力不能替代当前代码、真实平台或系统 VPN 验收。

## 实现细节

当前版本 0.2.0 在真实 HTTP 与 HTTPS MITM 共用转发管线中执行规则。普通请求先执行拒绝和请求头规则，响应按配置顺序执行响应头、文本替换或内置脚本。域名精确匹配，路径按前缀匹配；不扩展到子域名。

## JSON 响应脚本

新增 response-script 动作，script 仅接受编译进内核的 remove-json-keys，json_keys 为需要移除的根对象键列表。参数只描述数据，不接受源码、URL、文件路径或下载脚本。

内置 JS 在受限运行时中选择要移除的字段；Rust 保留其他原始 JSON 数值，避免大整数与高精度小数经过 JS Number 丢失精度。不递归扫描嵌套对象，不按名称猜测广告字段。没有命中键时保留原响应字节和校验头；正文改变后移除旧 Content-Length、ETag、Content-MD5 与 Digest，转发时重新计算长度。日志保留实际转发的处理结果。

限制：只接受未压缩的 application/json 或 application/*+json 根对象，正文最多 256 KiB，键最多 64 个、每个最多 256 字节且不重复。非 JSON、数组、压缩正文、错误配置或资源超限明确失败，不静默透传。正文有效时可能重新序列化，空白和字段顺序不保证保留。

脚本共享已有 250 ms 时间、32 MiB 堆、512 KiB 栈和全局四份运行时预算；放在阻塞工作线程执行，不占用 socket I/O 线程。取消后已开始的阻塞执行会在自身时间上限内结束。业务代码没有新增 unsafe。

## 接口

Rust Rewrite 与 Script 提供独立调用入口，process_response 用于异步管线。C ABI 2 的 mitm_start 扩展 rewrites 字段，能力位 4 表示内置流量脚本；旧字段兼容。Swift NativeRewriteRule 新增 script 与 jsonKeys 可选参数，匹配、执行和 JSON 正文处理均在 Rust。

用户 YAML 写为 script: remove-json-keys 和 json-keys: [ad]；C ABI 内部使用 json_keys，不是用户配置文件。本节旧内置动作接口不负责脚本下载；新主配置声明式资源下载与 QuickJS 调用采用 [插件与脚本](configuration/plugins.md) 的独立契约，不把任意资源 URL 当作旧内置动作源码。

普通 HTTP 请求经过上游 HTTP 代理使用 absolute-form；HTTPS 保留 CONNECT。代理错误不回退直连。当前调试监听仍只允许回环，LAN、认证、SOCKS、TUN、网关、DNS 路由与代理出站协议仍未交付。

## 验证

2026-10-10，macOS ARM64：Rust 38 项测试与 Clippy 通过，真实 Swift FFI 四组通过。新增真实 HTTP/HTTPS MITM 互通验证 JSON 字段移除、相邻及嵌套字段保留、日志正文、HTTP 转发长度与后续规则；实际 Swift FFI 验证 HTTPS 脚本处理和日志。独立测试覆盖无匹配原文、高精度数字、未知脚本、重复/空参数、类型与压缩拒绝及正文上限。旧 HTTPS、MITM、JS 与生命周期回归保留。

未验证最低 macOS 14 运行、其他平台/架构、真实系统浏览器信任、真机隧道和网关。受限内置脚本方案不代表已通过 App Store 审核；公开发行仍需按实际行为披露和审核。

## 禁止行为（不允许做什么）

不得递归猜测广告字段、改变未命中正文、丢失非目标高精度数字，或在不支持的类型／压缩／超限输入上伪称处理成功。

违反输入、授权或资源边界时，使用实际模块的既有错误／拒绝路径，不伪造成功或擅自扩大权限；具体失败后果以上文流程和公开契约为准。
