# 原生复写执行

## 职责（干嘛的）

对应源码：`src/configuration/rewrites/execution.rs`。在请求／响应阶段执行主配置及已加载插件的原生复写，匹配 URL 与 when 条件，输出继续、受限脚本、生成响应或明确路由指令。Message 是受界限约束的请求视图；Outcome 不是系统接管或授权结果。

## 目标（想达成什么）

每阶段按既定来源顺序选择第一条完整命中的规则，条件读取该阶段修改前的输入；主配置、插件顺序和 MITM 排除边界不因执行器优化或前置探测而改变。明确区分正常不匹配、规则拒绝、生成响应与执行错误。

## 禁止行为（不允许做什么）

不得将脚本错误、非法正文／头或缺失绑定转为 Continue／DIRECT，不得由插件覆盖主配置禁止解密的范围。禁止用复写生成的 HTTP 成功响应证明实际网络链路可用；前置检查不执行这些响应或脚本来绕过真实探测。

## 输入、输出及调用关系

Document 的阶段入口与已加载 Bundle／Bindings 接受有界 Message，对 URL、方法、头、正文、查询和响应状态进行声明条件匹配，再执行已校验动作。Cow 借用未修改内容，修改时受原有正文／头限额约束。脚本仅返回绑定供专用 JS 管线执行，不直接持有外部裸指针或下载脚本。具体动作字段、条件和主配置优先级见[plugins.md](../plugins.md)与[http.md](../../http.md)。

## 前置检查的必要代理集合

内部 preflight_rewrite_outbounds 从主配置和已加载插件中启用的原生代理复写提取明确节点引用；无节点的 proxy 和禁用规则不计入。不运行响应生成或 JS，不改变正式路由来强行覆盖节点。条件可达性未证明时采用保守集合；探测实际路由没有覆盖某必要代理则拒绝，不能把 DIRECT 成功算给该代理。

## 生命周期、错误及验证边界

执行依赖同一配置、插件及命名脚本快照；其内存和文件引用按原有预算与会话权限释放，外部保留对象不恢复活动权限。字段、输出、脚本及头正文错误沿统一 Error 返回，不在本模块重定义错误编号。

对应测试为`tests/test_configuration_rewrites_execution.rs`及`tests/test_rewrite_pipeline.rs`；必要代理集合的主配置、插件与禁用边界见`tests/test_vpn_preflight.rs`。这些测试不证明任意远端 JS、所有 HTTPS 服务或系统 VPN 已验收。
