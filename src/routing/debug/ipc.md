# ipc.rs 代码说明

## 职责（干嘛的）

对应源码：`src/routing/debug/ipc.rs`。模块提供独立本地 Debug 控制通道；目标是普通配置、订阅或业务命令无法注入调试权限，授权例外也不能逃出会话和资源边界。

## 目标（想达成什么）

只允许经独立认证和逐操作授权的有限时调试，失联、到期或撤销后不保留活动例外。

## 入口与协议流程

Service 从受保护策略读取准入规则并创建私有本地端点；Client 连接后核验系统对端身份，完成 Ed25519 挑战证明并获得有期限的 grant。序号、连接标识及完整载荷进入证明，重放或跨连接搬用不能恢复授权。replace／clear／status／close／audit 均重新验证身份和各自权限；具体 OS 签名验证由 platform/debug_identity.rs 复用。

## 状态、撤销与资源

调试规则与 grant 只存内存，TTL 必须有效且不超过 grant 剩余期限。替换、关闭、失联、到期或认证失败撤销旧视图和对应活动例外，旧引用不延长权限。读帧、策略、连接、审计、任务及内存均有独立上限；关闭等待端点与必要工作退出，不把 Drop 取消意图冒充完成。

## 安全边界与验证

策略、凭据、帧及参数须先验证再执行；拒绝缺权限、不可信签名、重放和超限，错误沿中央 ErrorInfo 返回，审计不保存密钥或规则正文。不支持的安全平台明确拒绝，不能开启开发绕过。完整约束见 [Debug 本地 IPC 安全规范](../../../AGENTS/Debug本地IPC安全规范.md)；运行示例 [debug_ipc.rs](../../../examples/debug_ipc.rs)，真实执行及签名分支范围见 [test_routing_debug_ipc.md](../../../tests/test_routing_debug_ipc.md)。本地夹具不能替代发布签名或真实系统权限验收。

## 禁止行为（不允许做什么）

禁止 TCP／UDP Debug 监听、身份自报即授权、重放证明、无 TTL 规则和配置注入控制操作；不得将旧引用或已过期 grant 作为活动权限。

违反输入、授权或资源边界时，使用实际模块的既有错误／拒绝路径，不伪造成功或擅自扩大权限；具体失败后果以上文流程和公开契约为准。
