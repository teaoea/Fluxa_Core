# runtime.rs 代码说明

## 职责（干嘛的）

对应源码：`src/routing/runtime.rs`。本页说明实现职责、数据流程和边界；公开调用的请求／响应契约单独维护于 `Documentation/`，开发约束维护于 `AGENTS/`。

## 目标（想达成什么）

将本地、插件和远程来源编译为不可变有效规则与诊断，保持显式优先级及可校验来源。

## 主要流程与模块协作

GenerationInput 有界解析原始来源，Snapshot 归一化、去重、保守裁剪并构建索引；store 管理内存发布／只读恢复，background 管理生成与取消，来源重算可验证裁剪依据。

## 输入、输出与失败边界

输入来自受约束的配置、明确授权的资源或校验后的网络数据；各入口的实际类型、字段和值域以下文及对应源码为准。正常结果只能说明该模块完成其职责，不能推定网络接管、其他模块初始化或外部权限已经成功。非法输入、协议错误、系统故障、取消和资源不足沿用 `src/error.rs` 的真实分类；不静默改为 DIRECT，也不修复或覆盖外部配置。

活动资源由 Core 的会话身份、有效租约、取消及明确关闭操作管理；只读快照引用不构成活动权限。内存与任务的实际存活期计入对应预算。具体模块没有活动任务时，不因本说明增加后台线程或额外权限。

## 匹配顺序（2026-10-16 dev）

内核正式来源为 `Layer::Local`、`Layer::Plugin`、`Layer::Remote`，不是两层模型中的占位注释。来源定义本身不承担排序；`Layer::ORDER` 和独立 `SourcePriority` 显式规定 **本地 → 插件 → 远程**。插件当前可以没有规则，未来加载插件时直接产生 Plugin 来源，不必再修改来源优先级算法。

1. 有效 Debug Overlay 保持在正式规则之前；认证、授权、TTL 和会话隔离不变。
2. 正式特殊 REJECT 不区分来源，类型范围是精确 DOMAIN、IP-CIDR、PORT、TRANSPORT（含完整匹配的域名/传输组合）。DOMAIN-SUFFIX、DOMAIN-KEYWORD 的单独 REJECT 按普通规则，不获得特殊拦截优先级。
3. 普通规则先比较来源，再在同一来源内依次比较 **process-name → protocol → port → domain → domain-suffix → domain-keyword → ip-cidr → geoip**；同来源同类型按原始顺序。GeoIP 属于 IP 阶段，显式 CIDR 在同来源 GeoIP 前；远程不导入 process-name。
4. `final` 对应配置 fallback，只在所有来源均未命中后使用。global 忽略普通规则，保留特殊 REJECT，其他流量使用 fallback；direct 保留特殊 REJECT，其他流量直连。

域名目标先执行域名阶段，完整域名条件命中后跳过 IP 阶段，包括 IP 拦截。无域名命中才解析真实地址；数字 IP 直接进入 IP 阶段。global/direct 中已经忽略的普通域名不能阻断 IP 拦截检查。需要 IP 而地址尚缺失时，DNS 前返回待解析，不能提前按兜底放行。

索引 `RuleClass` 仅描述存储槽。为保留原有平铺记录宽度，Plugin 和 Remote 共用以 `PluginRemote` 明确命名的同类型候选槽；编译、未裁剪参考构造和文档顺序验证都强制插件在远程之前，因此共享槽保留更高来源的最早命中。最终裁决读取规则真实 SourceIdentity，绝不把共享存储槽误当成同一业务来源；不按类别编号大小决定优先级。

## 示例与保守裁剪

| 本地 | 插件 | 远程 | 目标 | 预期 |
| --- | --- | --- | --- | --- |
| 后缀 example.com → 代理 | 关键词 example → 直连 | 精确 a.example.com → 代理 | a.example.com | 本地代理 |
| 无 | 关键词 example → 直连 | 域名+TCP → 代理 | a.example.com/TCP | 插件直连 |
| 精确 a.example.com → 直连 | 精确 a.example.com → REJECT | 无 | a.example.com | 特殊拦截 |
| 精确 a.example.com → 直连 | 后缀 example.com → REJECT | 无 | a.example.com | 本地直连；普通后缀拦截不越级 |
| 端口 443 → 直连 | 无 | 精确 a.example.com → 代理 | a.example.com:443 | 本地端口直连 |
| 同来源精确 a.example.com → 直连；同来源域名+TCP → 代理 | 无 | 无 | a.example.com/TCP | 组合协议代理 |

合并完全相同条件/动作/出站的重复规则并保留来源记录；仅可证明完全覆盖时裁剪，跨类型保守保留。Plugin/Remote 共享槽的覆盖判断以强制生成顺序为前提；来源顺序异常的文档不能加载。拦截不因为范围重叠直接裁剪。部分后缀、CIDR、端口重叠继续保留。

## 新主配置的编译与执行边界

新主配置的完整本地规则编译和提供者来源合并已接入当前工作区；规则编译不代表完整系统 VPN 启动。新主配置已提供标量到本地正式候选快照的适配、端口+域名组合与包含 PRIVATE 后缀的 PSL 租户标签关键词匹配。GeoIP Ready 绑定、macOS 进程归属及真实报文 QUIC 已接入，具体边界参见《主配置》。远程提供者 policy=reject 时忽略后缀/关键词的过滤由 providers::document 导入阶段落实，执行范围见 Subscriptions.md。声明式插件只读加载与 ID 优先级见插件专项，Plugin 来源与宿主导出往返可独立测试。

DOMAIN/DOMAIN-SUFFIX 的 protocol: tcp/udp 必须两个条件同时命中；不匹配协议不能遮蔽 IP。全域 TRANSPORT 只允许 REJECT；不能把 UDP 当 QUIC。完整示例由真实编译入口验证；尚未接入的 DNS/启动编排不能以纯查询代替，提供者生命周期见 Subscriptions.md。

## 文件、索引与生命周期

用户输入保持 YAML。当前生成产物为 `runtime-rules.bin`，保存缓存格式版本 6 的小端二进制平铺索引（来源/拦截语义更新后拒绝旧缓存，必须从原始来源重新生成）和严格校验的规则文档。加载直接查询索引字节，不重建哈希表、域名 Trie、IP 前缀树或关键词自动机。格式版本与宽度以 `src/routing/cache.rs` 和 `src/routing/flat.rs` 为准；版本不兼容时拒绝加载，须从原配置及订阅重新生成，不能混用历史缓存。文件读入仍有系统复制，索引借用不可变字节，文档仍需反序列化，不表示整个加载过程零分配。规则文档 format_version 为 1；来源、规则原序号、策略、出站和删除报告保持完整。

2026-10-21 起，Store 只负责内存发布及现有文件的只读加载，不创建目录、锁文件、临时文件或磁盘缓存，不迁移 YAML／SQLite。`Store::memory()` 在内存生成与更新，`Store::open(file)` 只读加载宿主明确提供的现有绝对文件路径；`Snapshot::to_binary()` 和后台服务 `export_binary()` 返回有界内存编码，保存和原子替换由宿主负责。内存发布失败保留旧快照；磁盘保存失败由宿主处理，Core 不伪造 fsync 完成。只读打开拒绝最终符号链接、非普通文件、超限及检测到的读取期间变化；宿主仍须保证父目录与来源可信，摘要仅检测损坏，不替代授权。历史写盘性能与断电恢复证据不用于当前实现。

提交后新请求读取新快照；已开始事务/连接继续完成既定任务，连接只保留必要决策和活动资源，不持有整份旧规则快照；高频请求不读取配置或缓存文件，不保存失效决策缓存。共享客户端使用进程内不可复用整数句柄，弱引用不会延长规则寿命。生成由有界后台任务执行；生成和关闭交错时提交拒绝。取消不会强行终止正在执行的编译代码，任务在提交前丢弃结果，完成清理前不允许同一实例启动第二个任务。

精确域名用哈希表，后缀用反向标签树，IPv4/IPv6 用压缩二进制前缀树，端口用重叠区间预编译表与二分查询，传输枚举直接索引，关键词用 Aho–Corasick 连续 NFA。索引保存各类别最早候选，查询不排序、不为单次请求创建并行任务。

域名已命中时固定使用域名决策；直连实际拨号仍需 DNS，但解析结果不重新匹配 IP 规则。未命中域名规则时才通过 DNS 进入 IP 阶段；解析失败明确失败。此时逐个检查地址候选，IP REJECT 只排除该 IP；还有允许地址就继续评估和尝试，全部被拒绝才返回 REJECT。不可用代理及执行错误仍明确失败，不默认 DIRECT。Fake-IP 通过所属解析器与有效代次还原域名再解析；合成地址不参与真实 IP 规则或连接。数字 IP 不查 DNS。纯 evaluate 是诊断查询，不能作为网络连接已建立的证明；域名未命中且缺少真实地址时返回的兜底也不能替代 DNS 后的实际决策。

## 限制与验证状态

最多 100000 条输入规则、64 个来源；普通规则值最多 253 字节，端口/域名组合最多 259 字节，出站名称最多 128 UTF-8 字节，YAML 最多 32 MiB、深度 32、事件数 3000000，FFI 保留既有 JSON 缓冲区上限，大输入使用有界 YAML 文件。全进程规则预算 512 MiB，按条目、域名标签和关键词长度预留，同时计算编译临时对象及新旧快照；高复杂度输入可在达到数量上限前失败，不仅提升数量上限。

Rust 业务模块无 unsafe。索引测试分别与同语义线性参考匹配器及未裁剪原始输入参考匹配器比较；发布前还需完成全部 Rust/真实 Swift FFI、最终优化构建性能记录、远程发布及 App 接入验证。当前文档不表示七步交付已经完成。

## 后台更新与连接行为

Swift 的默认 update 为 async；C ABI 通过 runtime_rules_begin / runtime_rules_begin_file 返回任务 ID，runtime_rules_job 查询状态，runtime_rules_cancel 取消尚未提交的任务。同步规则更新 FFI 已移除，Rust 离线 Store API 和基准仍可同步调用相同的共用生成与提交流程。

| 状态 | 新连接 | 已建立连接 | 活动文件及快照 |
| --- | --- | --- | --- |
| 后台加载、去重、裁剪、索引编译及完整验证 | 旧规则 | 旧连接快照 | 保持旧版本 |
| 临时文件准备完成，尚未原子提交 | 旧规则 | 旧连接快照 | 保持旧版本 |
| 原子提交成功 | 新规则 | 保持原快照及正常读写 | 切换新版本 |
| 编译失败或提交前取消 | 旧规则 | 保持原快照及正常读写 | 不替换旧版本 |
| 尚未有任何有效初始规则 | 明确未配置错误 | 不伪造已有连接 | 不回退直连 |

工作线程不占用网络请求锁。提交期间仅短暂持有快照提交锁，在权限和基线检查后切换内存快照，不执行文件替换或目录同步。状态查询返回最新任务的编译中、成功、失败或已取消，不包含日志或规则正文。

每个规则实例最多一个在途任务；重复提交明确拒绝，不建立无界队列。全进程最多四个在途生成任务，输入临时配额 128 MiB，另有原规则快照/编译预算 512 MiB；额度随资源释放归还，不为短查询创建线程。任务关闭后仍在运行的编译不能重新提交旧结果。取消已越过提交点的任务不能回滚完成的文件，状态会明确反映结果。

新增确定性 Rust 测试通过受控加载器暂停后台任务，验证这段时间新建的真实 TCP 连接采用旧版、提交后新连接采用新规则，以及已建连接继续读写；同时覆盖失败保留文件、取消、关闭并重开、四任务配额耗尽和回收。真实 Swift FFI 验证 50001 条规则的后台更新、异步等待、并发查询结果只属于完整旧版或新版，以及 YAML 后台失败保留快照。

全量默认并发回归曾遇到测试 DNS 同号 TCP/UDP 端口占用。修正测试夹具，仅对 AddrInUse 有界重试后完整回归通过；没有修改 DNS 业务的错误处理，也没有跳过失败测试。


## 独立旧 Clash 订阅 API 与持久化

订阅使用根字段 `payload`，每行严格采用 `DOMAIN,value`、`DOMAIN-SUFFIX,value`、`DOMAIN-KEYWORD,value` 或 `IP-CIDR,value`。IP-CIDR 统一支持 IPv4/IPv6。小写类型、第三列、IP-CIDR6、no-resolve、重复键和未知字段均明确拒绝。动作由订阅元数据 `policy` 指定，代理出站由 `outbound` 指定；省略代理出站时在生成快照时继承主配置出站。原始订阅不改写。该独立 API 的旧格式不能传给主配置提供者；根目录 rules.yaml 现为新的小写 rules 正文。

后台任务接收原始 payload，合并、去重、裁剪后生成二进制平铺缓存；宿主保存与内存更新边界见前文，性能测量见 [规则性能测试](../../tests/test_flat_cache_round_trip.md)。

## 规则准入与匹配契约

当前修改暂缓提交、推送和发布。以下描述本地实现，不代表 App 已更新依赖。

- RuleClass 只命名索引槽位，不实现 Ord，不按编号选择规则。裁决顺序由命名列表表达，本地/远程映射显式匹配；Debug Overlay 不增加正式类别编号。
- Snapshot::generate 保留原始来源产生的报告，标记 VerifiedFromSources；仅加载生成 Document 时报告为 StructuralOnly。数量和引用校验不能证明删除理由。
- 原始来源可用时，verify_against_sources 重新生成并比较全部值。伪造但结构合法的 Covered/Conflict 报告不能视为可信诊断。
- from_document 在创建集合与索引前按文档扫描估算并预留资源；不为估算复制来源规则。迁移和订阅入口同样在解析前预留预算。
- GenerationInput 不公开 Deserialize，只从有界 from_yaml 构造；返回对象持有解析预算直到消费/释放。宿主主动复制值或自行分配原始输入不属于分配器硬限制。
- 预算系数集中定义并采用 checked 算术；它是资源准入估计，不是实际堆分配计量。高标签数和大规模关键词压力仍须测量校准。
- Router 仅在编译时 lookup 整数句柄，后续匹配直接使用 Arc<Snapshot>，不逐请求访问全局注册锁。
- Rust 诊断入口 from_yaml_diagnosed 返回阶段和来源整数序号，不输出域名、出站正文或凭据；普通入口/C ABI 错误类别保持兼容。

### 历史 API 专用调试 Overlay（现行授权与撤销见 Debug本地IPC安全契约.md）

Session::new、replace、status、clear、close 为本地 Rust API；Router::with_debug 显式绑定当前视图。没有 YAML、订阅或持久化声明入口。宿主本地控制接口必须自行完成认证和权限检查；本轮没有创建控制服务器，也没有提供尚未实现的认证保证。

每条 DebugRule 必须提供 lifetime_seconds，单位秒，范围 1–3600；空、0、超过一小时返回 InvalidInput，失败保留旧方案。内部保存 UTC Unix 过期时间及单调时钟截止点，不保存会不断递减的剩余秒数。截止点到达即不可匹配；API 访问和决策清除过期条目，即使旧视图仍被连接持有也不能延长有效期。全过期状态下释放会话持有的方案；实际引用内存随最后所有者释放，不强制释放正在被访问的对象。

调试命中先于正式规则，允许覆盖正式拦截。清除/替换后新 Router 取新视图，既有视图保持原版本但同样受截止时间约束。不修改正式规则文件或已建立连接的出站。

protocol 可在 API 中限定 DOMAIN、DOMAIN-SUFFIX、DOMAIN-KEYWORD 的 TCP/UDP 条件，限定条件优先于普通调试域名条件；同一调试层有效拦截仍优先。不允许全域传输直连/代理，也不接受不具备识别能力的 QUIC。

可运行示例：cargo run --example runtime_rules_audit。示例只验证本地决策、来源重算和会话清除，不创建真实网络连接。C ABI/Swift 调试 API、App 页面、已认证控制服务及其真实互通尚未交付，不能把 Rust API 测试视为上述能力通过。


### 资源估算校准

系数是保守准入估算而非分配器硬配额；单机样本不能证明所有并发和输入形态下都低于 512 MiB。历史测试矩阵、原始测量结果及未测项见 [规则性能测试](../../tests/test_flat_cache_round_trip.md)。

## 主配置的远程来源字段

主配置 rule-providers 采用 name/url/policy/enable/update-time；远程正文为小写 `rules` 列表，不携带策略。宿主拥有下载、设备本地日历、目录与文件，Rust 内核负责只读校验、编译、内存发布及关闭；具体接口和失败后果见 [规则提供者生命周期](../providers.md)。声明式插件已接入只读加载；代理提供者仍暂缓。旧 subscriptions、kind、id、enabled、policy: proxy + outbound 和 payload 不用于新主配置。

## 报文、进程与国家条件

主配置接入及语义见 [主配置](../configuration.md#完整规则编译与裁决接口2026-10-17)。`ProcessName` 精确名称使用 `#process:` 独立索引键，`GeoIp` 国家使用 `#US` 等隔离键；这些键不接受为域名，防止跨类型冲突。QUIC 独立后缀森林与普通端口森林共用目录布局，条件标签不是优先级。候选槽数量保持 21，分别合并后按真实来源/类型/序号裁决。二进制缓存 v6 验证键、条件、来源及候选关系；旧版本拒绝并从原始来源重建。

实际 MAC 进程归属只由平台模块查询，纯路由诊断没有流身份而跳过该项。GeoIP 数据绑定不持久化到规则缓存，恢复后必须重新绑定同来源 Ready 数据库；缺失不能返回兜底成功。编译与查询的系统/资源失败保留现有整数错误协议。

进程规则来源约束：process-name 只在 macOS 本地配置参与；iOS/iPadOS/tvOS 本地编译忽略；远程规则集一律单行忽略（direct、reject 或节点策略均相同）。无法由操作系统确定流归属时跳过进程规则继续匹配，禁止接受远程自报进程身份。

## 禁止行为（不允许做什么）

不得用共享索引槽代替来源身份、未经证明裁剪规则、用失效快照恢复授权，或省略严格校验来改善性能数字。

违反输入、授权或资源边界时，使用实际模块的既有错误／拒绝路径，不伪造成功或擅自扩大权限；具体失败后果以上文流程和公开契约为准。

混合策略表达式由[统一解析器](strategy.md)校验；索引保留完整候选顺序和表达式，不把末尾reject提前作为特殊拦截。
