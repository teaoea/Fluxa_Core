# Fluxa Core

跨平台 Rust 网络代理内核，作者：可莉唯一的狗。自有代码采用 MIT，许可记录见 [LICESE.md](LICESE.md)。SwiftUI App 位于独立仓库。

技术说明统一保存在 [Documentation](Documentation/Overview.md)，包括 [公开整数错误协议](Documentation/错误代码查询表.md)、[开发强制规范](Documentation/Rust网络代理内核统一错误代码体系设计、实现与审查.md)、[验证与审查记录](Documentation/ErrorSystemReview.md)、[版本约定](Documentation/Versioning.md) 和 [发布流程](Documentation/Publishing.md)。

App 使用固定远程 Swift 包和经校验的静态二进制；未完成能力明确拒绝。文档及测试不代表系统 VPN 或全部目标平台已验收。
