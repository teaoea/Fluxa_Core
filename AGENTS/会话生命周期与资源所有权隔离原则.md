# 会话生命周期与资源所有权隔离原则（MUST）

本文是用户明确规定的强制开发约定。适用全部 Rust 内核会话、解析器、快照、连接池、监听器、资源租约、后台任务以及公开 API/FFI。技术检查通过不能替代独立业务语义验收。本文规定目标契约，不代表当前全部模块已经实现或验收。

## 强制原则

1. Rust 内核必须独立管理会话生命周期，不得依赖外部调用方释放对象来完成会话关闭。
2. Arc、Weak 及其他引用计数机制只能用于对象生命周期管理，不得直接作为业务资源占用权的判断依据。
3. 会话关闭必须主动撤销其活动资源使用权，并阻止新的资源申请。
4. 旧解析器和旧快照即使仍被外部引用，也不得阻止已经释放的资源被新会话合法使用。
5. 绑定冲突必须基于有效租约及真实系统资源占用判断，不得仅根据对象引用计数判断。
6. 活动 Socket、连接池、监听器及后台任务必须具备独立于快照引用的确定性释放机制。
7. 会话关闭后，旧对象不得重新创建、占用或恢复已撤销的资源。
8. 活动操作必须通过会话身份、Generation 和有效租约进行验证。
9. 会话撤销与资源获取之间必须保证并发正确性，禁止检查与使用之间的竞态漏洞。
10. 资源关闭必须具备明确的完成状态，禁止将仍处于释放过程的资源标记为已释放。
11. 旧快照实际占用的内存仍必须计入资源预算，禁止以逻辑关闭为由忽略内存占用。
12. 会话关闭、重复关闭、并发关闭、启动中关闭，以及旧引用长期存活等场景必须具有可验证的行为契约。
13. 上述设计必须通过独立业务语义审查，不能仅以编译成功或测试通过证明正确性。

## 操作语义

| 操作 | 含义 |
| --- | --- |
| `close_session()` | 撤销会话权限、停止活动资源，并等待必要的资源释放完成；内核负责全过程及完成状态 |
| `drop(handle)` | 仅减少 Rust 对象引用计数；引用计数不能作为内核关闭操作的完成条件 |

关闭意图与关闭完成必须区分。Closing 表示权限已撤销但必要清理仍在进行；Closed 只能在必要资源释放完成后返回。重复及并发关闭必须得到同一确定结果，不能因为一个调用已移走对象就向其他调用提前报告完成。

旧对象允许保留只读数据用于受限展示，但不得以旧身份重新获取、恢复或使用活动资源；活动操作返回现有结构化状态错误，不降级 DIRECT，不伪造成功。真实内存所有权仍必须持有对应预算，直至实际释放。

## 绑定事务

请求绑定资源 X → 查询内核 BindingManager → 检查有效租约与真实占用关系。有效占用冲突则拒绝；没有有效租约时申请绑定，在实际系统绑定成功后登记有效租约。绑定过程中关闭会话，必须拒绝登记并回滚已取得的系统资源。

逻辑资源与系统资源必须区分：Fake-IP 地址空间租约不等于系统监听 Socket；不能用逻辑表插入成功证明系统绑定成功。会话权限撤销与租约获取/提交必须有同一同步边界或等价可验证事务，不能仅在操作开始检查一次权限。

## 内核与前端职责（MUST）

内核负责完整生命周期，前端只负责交互和必要操作系统能力协调，禁止赋予前端管理内核运行逻辑的能力。前端可以传递用户启动、关闭、配置修改等操作意图，但不能自行裁决内核状态、恢复策略、资源占用或关闭完成；不能要求前端释放旧解析器/快照、管理后台任务或重试资源绑定来补足内核生命周期。

| 功能 | Rust 内核 | 前端 |
| --- | --- | --- |
| 内核生命周期管理 | 完全负责 | 不得直接管理 |
| 启动前置检查 | 完全负责 | 展示检查结果 |
| VPN 接管决策 | 完全负责 | 必要的系统接口协调 |
| TUN 数据处理 | 完全负责 | 不得干预 |
| 代理节点可用性验证 | 完全负责 | 展示结果 |
| 规则引擎及优先级 | 完全负责 | 展示或提交用户配置 |
| DNS、GeoIP | 完全负责 | 展示结果 |
| 解析器与连接池 | 完全负责 | 不得持有控制权 |
| 快照及资源租约 | 完全负责 | 不得管理 |
| 错误处理与恢复 | 完全负责 | 展示错误 |
| 网络健康检查 | 完全负责 | 展示状态 |
| 配置验证及提交 | 完全负责 | 传递用户修改请求 |
| 内核运行状态 | 唯一业务权威 | 只读展示 |
| 用户风险确认 | 验证授权 | 展示确认界面、传递选择 |
| 操作系统权限 | 验证权限及结果 | 必要时协调系统授权 |

## 验证与交付

必须实际测试外部旧 Arc 长期存活、旧对象操作失败、新会话重新绑定、正在启动/查询/转发时关闭、重复及并发关闭、资源释放完成、租约准入失败原子性，以及关闭后的真实内存预算。代码、中文注释、可运行示例、文档和 L1–L4 证据同步维护。禁止把任务取消请求或对象析构推断为系统资源已经释放。
