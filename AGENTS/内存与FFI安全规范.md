# 网络引擎内存管理规范

## 安全 Rust 为默认

业务模块禁止不安全代码。优先所有权、借用、切片、标准容器、RAII 以及线程安全同步原语；不能用泄漏对象、`static mut`、`transmute`、无检查索引或随意实现 `Send`/`Sync` 绕过编译器。只在 FFI 或操作系统接口有必要时考虑局部例外，必须记录无法用安全 API 完成的原因、安全不变量和验证方式。禁止全局关闭不安全代码检查。

当前 `ffi.rs` 的例外允许带统一前缀的符号导出属性，以及输入借用、输出复制两个必需的 C ABI 内存操作。其余对象均通过不可复用句柄传递。Rust 2024 的 `unsafe(no_mangle)` 是符号导出声明，不意味着函数体包含不安全内存操作。后续新增裸指针接口必须重新审查，不能沿用现有说明。

## 所有权与释放

通用 `Registry<T>` 集中管理资源所有权、数量上限与句柄校验；各类资源共享一套逻辑，释放时通过 Rust 的 Drop 完成清理。Rust 注册表拥有实例，外部调用方只持有不可复用句柄。创建失败返回零，重复释放、零句柄和过期句柄均返回错误，不访问外部内存。当前 Engine 拥有客户端配置、CA、代理监听及捕获队列；代理拥有监听任务，会话任务拥有套接字与缓冲区。外部调用方不拥有这些资源的地址。

销毁资源应先拒绝新任务，再发送取消信号，关闭连接以唤醒阻塞操作，等待任务退出，最后释放资源。不能让未完成回调引用已销毁对象。Core 的公开接口必须在并发、错误和取消路径维持相同的资源释放契约。依靠明确的关闭操作及时释放；析构仅作为兜底。

跨语言优先传递值类型。确需缓冲区时，文档必须分别定义借用期限、长度和容量、是否允许空指针、线程限制、唯一释放入口。Rust 分配的对象只能由 Rust 对应释放接口释放；外部调用方分配的对象只能由 外部调用方释放。禁止保留调用方临时指针或向 外部调用方返回短命借用。

## 输入、并发与资源上限

当前实例注册表上限 64，编号使用 checked_add，不回绕复用。锁保护创建、查询和释放，锁中毒明确失败。禁止在持有注册表锁时进行网络 I/O、调用外部回调或等待任务结束。

每个后续协议解析器必须先检查帧长度、字段长度、偏移和算术溢出，再分配或访问内存；使用有上限的缓冲区。连接数、任务数、队列长度、日志正文、解压输出和 JS 沙盒内存必须设独立上限。超限必须返回明确错误，不静默截断协议安全字段。

敏感数据不得进入错误字符串或日志；缩短凭据、解密正文和密钥的驻留时间。确需清零时使用经过审核的专用依赖，不以普通赋零声称可靠擦除。

## FFI 错误与验证

Rust panic 不跨越 C ABI，返回稳定状态码；锁中毒不强制恢复。不得把内部失败转换成连接成功或直连回退。若未来使用 abort 编译模式，必须明确 catch_unwind 无法捕获该模式的进程终止。

每次边界变更增加有意义的用例：无效与过期句柄、重复释放、溢出、容量限制、并发取消、创建失败和错误路径清理。引入不安全代码时，增加 Miri 或适用平台的内存检测；报告实际运行环境，不能将未运行工具写为已通过。执行结果与未测项保存在对应测试文档，不在开发约束中维护阶段性通过记录。

HTTPS 边界契约：输入空指针、零长度和超过 12 MiB 的长度被拒绝；有效地址与调用期间无并发修改由调用方保证，Rust 不保存借用。输出容量不足不写入，返回所需长度；目标可写且不重叠由调用方保证。Rust 响应缓冲区以 Arc 保持复制期间存活，释放时用 Zeroizing 清理；不得据此宣称 TLS 依赖和所有中间副本已可靠清零。FFI 的 8 并发上限在解析 JSON 前获得，限制大正文的同时分配。

MITM 与 FFI 响应共用 ByteBudget/ByteLease：配额跟随所有权释放，失败和取消路径自动归还。日志每实例最多 64 条或 32 MiB，所有实例合计最多 64 MiB；读取后的临时副本仍有严格正文上限。FFI 待复制响应总量最多 32 MiB，单份输出最多 24 MiB。MITM 全局最多 8 个活动连接，未完成会话 60 秒超时。显式停止取消、等待全部工作任务退出后返回；析构发送取消，异步清理作为兜底。

当前 Apple package 静态链接 Rust 平台库；共用执行器由进程拥有，线程数固定为 2。本次不产出或分发动态库；静态执行器随进程结束回收，不提供卸载接口。

## JS 运行时

JS 业务使用 rquickjs 安全 API，没有新增 unsafe；依赖底层 QuickJS 是 C 实现，不宣称整条依赖链不含不安全代码。每次执行的 Runtime/Context/值拥有明确生命周期，JS 指针不出运行时；跨实例 128 MiB 预算以 ByteLease 回收，超限先拒绝。内存、栈、时间与 JSON 结构上限详见 ../src/script.md。解释器中断不是硬实时抢占，运行时堆限额不是进程 RSS 限制；依赖漏洞和 JS 敏感堆清零不由此保证。配置来源策略必须由分发客户端执行。

DNS 业务无新增 unsafe。实例/查询/缓存预算详见 ../src/dns/mod.md；缓存关闭及配置替换按所有权释放，进行中的查询持有 Arc，结束后释放旧实例；不把关闭称为立即中断已进行查询。DNSSEC 底层密码学和网络组件适用各自实现与许可，不宣称依赖内部不存在不安全代码。

Fake-IP 业务没有新增 unsafe；映射使用受 Mutex 保护的值类型树和 ByteLease，容量及全局配额详见 ../src/dns/mod.md。重置保留地址游标，不把旧地址分配给其他域名；不是跨实例、跨进程的持久化地址身份保证。

局域网 DNS 服务采用 RAII 端口/任务所有权、有界 JoinSet 及服务/连接/请求信号量。每轮回收已完成子任务，停止取消并等待所有子任务结束；析构发送取消作为兜底。输入、报文、来源计数及期限详见 ../src/dns/mod.md。运行服务期间明确拒绝替换解析器。

路由快照以 Arc 和 ByteLease 持有，配置失败不替换旧快照；评估先克隆快照并释放配置锁，不持有注册表锁匹配规则。输入上限和预算见 ../src/routing.md；后台生成及连接任务必须分别遵守各自的租约、取消和资源预算。

## 共用出站资源与配置

会话及 FFI 缓冲句柄在进程内统一分配，溢出拒绝，跨实例不复用。DNS、路由、资源限制共享不可变快照；替换时原子提交，旧快照随在途请求的最后所有者释放。空闲检查任务持弱引用，析构取消，注册表锁外关闭；取消使阻塞读写释放 socket 及配额，不新增 unsafe。统计有界且不保存正文。

## 共用服务连接管线（v1.3.0）

HTTP/HTTPS/MITM 已统一使用配置 DNS、实际路由和受管理连接；取消、空闲回收及资源所有权均沿用共用管线。未配置能力明确拒绝，TLS 信任与域名解密范围不改变。实现、发布来源及完整验证边界见 [Outbound.md](../src/outbound.md)。

## ABI 错误查询与失败关闭

`nodus_core_last_error_copy` 的编码在 unwind 边界内完成；编码错误或 panic 使用由 error.rs 生成并在编译期核验的固定 SerializationFailed JSON。查询不分配句柄、不清除原线程错误；空目标或容量不足不写入。

`nodus_core_destroy` 先从注册表撤销句柄和 VPN 准备准入，再按既有顺序尝试所有独立关闭步骤。单步错误或 unwind 不跳过后续步骤；最终返回首个真实错误，其余仅记录有界清理诊断。不恢复中毒锁，不把失败视为所有资源都已关闭；重复 destroy 仍报无效句柄。旧 Arc 保留不构成继续使用活动出站或代理监听的授权。

示例 `cargo run --example ffi_error_query` 演示错误长度查询、容量不足不写入和句柄释放，不启动系统 VPN 或修改系统设置。真实失败关闭回归与结果见 `tests/test_ffi.rs` 及同名测试报告。
