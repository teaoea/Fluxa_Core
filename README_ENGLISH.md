
### Native conditional rewrites (local development)

The current local implementation accepts the updated `rewrites` declarations with `enable`, `phase`, and native AND conditions in `when`. Request actions include `reject`, `respond`, `modify-request`, `redirect`, `abort`, `direct`, and `proxy(name)`; `modify-response` waits for the actual upstream response. Bare `proxy` is valid and ignored. Named proxies reference a configured node and never fall back to direct on failure. Header/query existence and equality, method, response status/headers, content type, actual body length, and request-body text conditions are supported.

`minimal-mp4` provides a zero-duration, audio-free MP4 decoy for configured ad replacement. AVFoundation identifies its zero-duration video track; it has no playable duration and reader output contains no frame. Ad skipping and player compatibility remain client-specific and unverified. `transparent-png` is a 1×1 transparent PNG. Run the offline example with `cargo run --example execute_rewrites`; details and limits are documented in `Documentation/主配置.md`.

These changes are local and unpublished. Declarative plugins now load `mitm`, `rewrites`, and one `scripts: {name, url}` mapping. The `name` field is required; `js: response` references `name: response` exactly, even if the URL ends in response.js. Missing or unregistered resources are diagnosed and excluded from effective rewrite selection, without suppressing later valid rules. Main rules precede numeric plugin order, and main MITM exclusions always win. The App/host owns directories, downloads and persistence. Core receives explicit read-only file paths for main scripts, plugins, rules and GeoIP; neither Core nor Network Extension creates or modifies asset files. Compiled configuration stores bindings and absolute paths, not JS source. QuickJS runs on bounded isolated worker threads with rule-level js-ttl (default 3600 seconds), cancellation and real joins on manual clear. Capacity evicts idle workers only; multiple TTLs for one resource share the shortest TTL. See `Documentation/插件与脚本.md` for the JSON patch contract and validation limits. Existing preconnected streams and explicit local proxy hops cannot be rerouted by a native direct/named-proxy action and return Unsupported rather than claiming a route change. This does not establish system VPN, TUN, or complete main-configuration MITM activation.

Apple 平台最低版本、ARM64 架构与本地构建入口见 [Apple 平台构建](Documentation/Apple平台构建.md)；强制约束见 [全平台系统支持的最低版本](AGENTS/全平台系统支持的最低版本.md)。不支持 Intel Mac、Mac Catalyst、watchOS 和 visionOS；产物不自动上传。

Read-only configuration diagnostics, fixed integer error codes, logical source positions and UTF-16 editor offsets are documented in [Configuration checking](Documentation/API/配置文件检查.md). The Chinese and English default templates are `default_config.yaml` and `default_config_en.yaml`, with `final,direct`; Core returns their content and the host creates files. A missing named fallback node is an error and never falls back to direct.
